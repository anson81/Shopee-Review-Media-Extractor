Where exports are saved

Choose a folder and the extension writes each export into it itself. Without one, it asks Chrome to save the file — and any other extension that handles downloads can rename it, which is how files end up as download (2).zip. Chrome gives the final say to whichever extension was installed most recently, so that problem comes back on its own whenever one of them updates. Choosing a folder ends it for good.

Being gentle with Shopee

These slow the extension down on purpose. A big run makes hundreds of requests from your logged-in account, and asking too fast is what gets an account rate limited. The defaults are safe; raise them only if a run is being refused.

Where updates come from

Installing an update asks you to pick this extension's folder. That is a one-off, and it is the only way a browser lets an extension write to its own files.

Diagnostics

Runs a read-only check against whichever Shopee product page you have open, and reports what its endpoints actually return. Use it when something comes back empty — Shopee changes these without warning, and this says exactly what changed. It only reads: about five requests, the same ones the page already makes for itself. Nothing is downloaded and nothing on the page is touched.

Open a Shopee product page, then run this.
